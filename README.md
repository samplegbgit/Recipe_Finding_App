# 🍳 ProChef – Recipe Discovery App

**Live Demo:** [View ProChef](https://prochef-recipe-app.onrender.com)

## ✨ Features

- **Recipe Discovery:** Explore featured and trending recipes.
- **Recipe Search:** Search for recipes by meal name.
- **Cuisine Filtering:** Browse recipes by different cuisines.
- **Category Filtering:** Filter recipes by categories such as Chicken, Seafood, Dessert, and Vegetarian.
- **Recipe Details:** View ingredients, measurements, cuisine information, and cooking instructions.
- **Responsive UI:** Enjoy a user-friendly experience across different screen sizes.
- **Real-time API Integration:** Fetch recipe information dynamically from TheMealDB API.

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **Routing:** React Router DOM
- **Icons:** Lucide React
- **API:** TheMealDB API
- **Version Control:** Git & GitHub
